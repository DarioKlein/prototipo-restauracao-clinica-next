# Clínica Restauração — Sistema Clínico

A clinical management system for Comunidade Restauração, built with Next.js 16. The interface is in Portuguese.

## Modules
- **Acolhidos** — residents/patients management
- **Estoque** — medication inventory by intake modality, with stock movement tracking
- **Funcionários** — staff/employee management
- **Triagens** — screenings
- **Declarações** — declarations
- **Documentos** — documents
- **Modalidades** — modalities/programs
- **Relatórios** — reports and charts

## Running the app
```bash
pnpm dev
```
Runs on port 5000. The "Start application" workflow handles this automatically.

## Stack
- Next.js 16 (App Router, Turbopack)
- React 19
- Tailwind CSS v4
- Recharts (charts)
- @react-pdf/renderer (PDF export)
- TypeScript
